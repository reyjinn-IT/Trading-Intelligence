Trading Intellegence Handbook

Welcome! This guide is designed to be easily understood, even if you are new to the world of trading or programming. Trading Intellegence is essentially a "Smart Assistant" that helps you analyze Bitcoin (BTC) price movements.

Instead of manually guessing the market direction (which is often influenced by emotion or fear), this system uses strict mathematical rules to tell you exactly when to buy or sell.

Important Warning: This system is a tool (assistant), not a guarantee of profit. All risks of loss when you decide to trade with real money are entirely yours. Always start with simulation mode!

How to Run the System

This system runs locally on your own computer. You only need internet access so the system can pull the latest price data from Indodax.

Steps:

Open Terminal (or Command Prompt) on your computer, then type these commands sequentially:

# 1. Download or ensure you are in the application folder
cd TRADING

# 2. Activate the virtual environment
# On Windows:
.\venv\Scripts\Activate.ps1

# 3. Start the system
python main.py --server

After that, open your internet browser and go to: http://localhost:8000/terminal to view your smart assistant!

How the System Thinks (3 Pillars of Analysis)

When the system looks at a chart, it doesn't just guess. It gives an "exam score" on a scale from 0 to 1. If the score is good enough (above a predetermined threshold), it suggests trading. It looks at these 3 things:

Weight Pillar Name Simple Explanation
40% Market Structure Is the price overall going up or down? Like swimming, it's much easier to swim with the current.
30% Supply & Demand Finding out whether the current price is "overpriced" or at a "discount". We always want to buy when there is a massive discount.
30% Macro Sentiment Checking whether people out there are greedy (wanting to buy everything) or fearful.

Learning From History (Historical Patterns)

Humans often make repeated mistakes, and so does the financial market. This system is equipped with a Historical Memory feature.

  • Every second, it compares today's chart shape with charts from several years ago.
  • If the shape is similar to a past pattern that generated profit, it will use that data to predict today's price. This is exactly like seeing dark clouds to predict that it will rain soon.

Seatbelt (Protecting Your Money)

In trading, the most important thing is not how big your profits are, but how smart you are in protecting your capital from depletion.

Emergency Brake (Deadman Switch)

The system has a sort of heartbeat sensor. If your computer suddenly loses power, or the internet drops, the system will immediately scream to the exchange (Indodax) to CANCEL all your pending orders, so your money remains safe.

Smart Cut Loss

The system automatically calculates when it should "give up" if its guess is wrong. It will immediately sell your coins with a minor loss (maximum 2%) before the loss gets bigger and drains your funds.

For Advanced Users (API)

If you are a programmer who wants to connect this system with other applications (for example, making a Telegram bot), you can use these endpoints:

Endpoint Usage
/api/ticker?pair=btc_idr Gets the latest real-time Bitcoin price.
/api/evaluate?pair=btc_idr Commands the assistant to analyze and provide trading advice immediately.
