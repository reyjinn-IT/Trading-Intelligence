SYSTEM ARCHITECTURE

01. CONFLUENCE ENGINE
40/30/30 Model

The algorithmic core operates on a strict 40/30/30 scoring model to eliminate subjective human bias. A trade signal is only generated if the aggregate Confluence Score surpasses the internal threshold (MIN_CONFLUENCE_SCORE > 0.65).

  • 40% Market Structure: Evaluates EMA 18/50/200 alignment, Break of Structure (BOS) shifts, and MACD momentum vectors.
  • 30% Supply & Demand: Calculates proximity to Point of Interest (POI) zones, liquidity voids, and premium/discount arrays.
  • 30% Macro Sentiment: Ingests external data like the Crypto Fear & Greed Index and global volume deltas.
02. MACHINE LEARNING
Pattern Aggregation

We abandon static indicators in favor of In-Context Pattern Learning. The engine processes a 1,440-bar historical vector upon every tick to identify structurally identical setups from the past.

This empirical probability model computes exact target levels based on actual historical behavior rather than arbitrary R:R ratios.

03. DATA ROUTING
Multi-Pair Engine

Simultaneous connection to Indodax APIs handles real-time fiat and stablecoin conversions. Our latency optimized router can seamlessly switch between BTC/IDR and BTC/USDT without reloading the runtime state.
